# AmbientPad Live – Web-App

Pad-Sounds in allen 12 Tonarten für Worship. Läuft offline als Web-App auf iPhone und iPad (Safari → Teilen → „Zum Home-Bildschirm“).

- 2 Sets mit je 12 Tonarten, eigene MP3/WAV/M4A-Dateien
- Weiche Überblendungen, nahtlose Schleifen
- Steuerung per Bluetooth-Umblätter-Pedal (2 Tasten): links kurz = nächste Tonart, lang = zurück; rechts kurz = Start/Stopp, lang = alles ausblenden

Neue Version veröffentlichen: Dateien ersetzen und in `sw.js` die `VERSION` erhöhen.
